# 🏷️ Лайфхак по Топикам (GitHub Topics)

**Topics (Темы)** на GitHub работают как хэштеги. Они позволяют навести идеальный порядок в профиле, даже если у вас скопились сотни репозиториев.

---

## ⚙️ Как добавить топики вручную через сайт
1. Перейдите в свой репозиторий на GitHub.
2. В правой колонке найдите блок **About** (О проекте).
3. Нажмите на значок **шестеренки** (Settings) в углу этого блока.
4. В поле **Topics** начните вводить нужный тег и нажмите `Enter` или пробел.
5. Нажмите **Save changes** (Сохранить изменения).

---

## 🗂️ Готовые наборы тегов по вашим категориям

Чтобы ваши проекты красиво фильтровались, используйте для них стандартные наборы ключевых слов.

### 🖥️ Для Frontend-сайтов
*   `website` (обязательный корневой тег)
*   `frontend`, `ui`, `responsive-design`
*   Технологии: `html`, `css`, `javascript`, `react`, `nextjs`, `tailwind`
*   Суть: `portfolio`, `landing-page`, `dashboard`

### 🛠️ Для Электроники и Микроконтроллеров
*   `microcontrollers` (обязательный корневой тег)
*   `embedded`, `iot`, `hardware`, `electronics`
*   Технологии: `arduino`, `esp32`, `cpp`, `stm32`, `raspberry-pi`
*   Компоненты: `sensors`, `display`, `motor`

### 💡 Для Лайфхаков и Баз знаний
*   `lifehacks` (обязательный корневой тег)
*   `cheatsheet`, `awesome-list`, `documentation`, `guide`

---

## 🔥 Главная фишка: Мгновенная фильтрация
Как только вы раскидаете эти теги по репозиториям:
1. Зайдите в своем профиле во вкладку **Repositories**.
2. Вверху в фильтрах появится кнопка **Topic**.
3. Нажмите на тег `microcontrollers` — GitHub скроет всё лишнее и покажет только ваши проекты с платами и схемами.
